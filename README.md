# MATH ARENA v1.0

Mobile-first 1-minute mental-math duel frontend.

### Included
- 60-second timed duel
- Easy / Medium / Hard
- Streak-based scoring
- Accuracy and best-streak results
- Local best-score persistence
- Responsive UI
- No ads or subscriptions

This is the frontend game layer. Supabase authentication, persistent profiles, matchmaking, ratings and real-time multiplayer are connected separately.

**Never put database passwords, service-role keys, or other secrets in these files.**
